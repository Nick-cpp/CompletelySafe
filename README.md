# CompletelySafe
A terminal-based interactive novella in C

# Running a pre-build static binary

```
wget https://github.com/Nick-cpp/CompletelySafe/releases/download/1.0/CompletelySafe
chmod +x CompletelySafe
./CompletelySafe
```

# Building from source

```
git clone https://github.com/Nick-cpp/CompletelySafe
cd CompletelySafe/
gcc CompletelySafe.c -o CompletelySafe
./CompletelySafe
```
